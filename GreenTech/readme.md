# GreenTech Solutions – Final Project
This project is a multi‑page website created for the GreenTech Solutions client. The site demonstrates responsive design, accessibility, and basic JavaScript interactivity. It includes a homepage, About page, Products page, Blog/Resources page, Contact page, and a Final page. The goal of the project is to present eco‑friendly technology solutions and provide users with an easy way to learn about sustainability.

## How to Set Up and Run the Project
1. Download or clone the project folder.
2. Open the main folder named “GreenTech.”
3. Open any of the HTML files (such as `index.html`) in a web browser.
4. Make sure the folder structure stays the same:
   - `css/styles.css` for styling
   - `js/script.js` for JavaScript
   - `images/` for all images
5. The website will run locally in any modern browser (Chrome, Edge, Firefox, Safari).

## Technologies Used
- **HTML5** – Page structure and semantic layout  
- **CSS3** – Styling, layout, and responsive design  
- **JavaScript** – Form validation and product search filtering  
- **Responsive Design** – Media queries for mobile and tablet  
- **Accessibility Features** – Alt text, labeled forms, proper heading structure  

## Project Features
- Fully responsive navigation bar  
- Product catalog with images  
- Search bar that filters products  
- Contact form with validation  
- Blog/Resources section  
- Final page with project summary  
- Clean folder structure and validated code
